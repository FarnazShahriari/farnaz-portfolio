# Insights

Problem understanding and research. What did we learn, and about whom.

- One file per topic or research round, dated: `YYYY-MM-DD-short-title.md`
- Include: what was observed, who/what the source was (user testing, shadowing,
  workshop, etc.), and what it implies for the design.
- No design decisions here — just findings. Decisions go in `../decisions/`.
